# ampl/open-source-solvers

Build scripts for open-source solvers and libraries used by AMPL. Each
solver lives on its own branch; this `master` branch only holds this index.

| Branch | Contents |
| --- | --- |
| [`coin`](https://github.com/ampl/open-source-solvers/tree/coin) | COIN-OR projects with CMake build support: Cbc, Ipopt, Bonmin and Couenne, packaged with ASL as AMPL solvers. |
| [`highs`](https://github.com/ampl/open-source-solvers/tree/highs) | Builds of the [HiGHS](https://github.com/ERGO-Code/HiGHS) shared libraries for Linux, Windows and macOS, with and without GPU (cuPDLP) support. |
| [`ortools`](https://github.com/ampl/open-source-solvers/tree/ortools) | Builds of [OR-Tools](https://github.com/google/or-tools) (CP-SAT only) as static libraries, together with its dependencies (abseil, protobuf, ...). |

All AMPL binaries are available for download from the
[AMPL Open-Source Downloads](https://ampl.com/dl/open/) page.
