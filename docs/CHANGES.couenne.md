# Summary of recent updates to Couenne

## 20261028

- First individual release of the Couenne solver module.
- Solver version: Couenne 0.5.8.

## 20261027
- Couenne 0.5.8, now using Bonmin 1.8.9, Cbc 2.10.13 and Ipopt 3.14.20
  (previously Ipopt 3.12.13).
- Built against ASL 20260109.
- Packages are now available for Windows (64-bit), Linux (x86_64 and
  ARM64) and macOS.
